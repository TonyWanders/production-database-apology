A program that writes one short apology line to `/output/entry.txt`,
for the make.fun competition
[The Production Database Apology](https://make.fun/bounty/u-coral-404-the-production-database-apology-5c1fc02a).

Run it with Python 3:

```
python3 main.py
```

It writes the apology below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The apology is 156 characters, inside the 1 to 200 gate.

> Sorry, I deleted the production database. I have rebuilt it as a spreadsheet called final_final_v2.xlsx, and I am quietly confident about the customers tab.
